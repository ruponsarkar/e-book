**1.** Which work of Banabhatta refers to Bhaskaravarman of Kamarupa?\
বাণভট্টৰ কোনখন গ্ৰন্থত কামৰূপৰ ভাস্কৰবৰ্মনৰ উল্লেখ আছে?\
(A) Kadambari / কাদম্বৰী\
(B) Harshacharita / হৰ্ষচৰিত\
(C) Rajatarangini / ৰাজতৰংগিণী\
(D) Mudrarakshasa / মুদ্ৰাৰাক্ষস

**2.** The legendary city of Sonitpur, capital of Bana, is identified with present-day:\
বাণৰ কিংবদন্তিমূলক ৰাজধানী শোণিতপুৰক বৰ্তমানৰ কোনখন ঠাইৰ সৈতে চিনাক্ত কৰা হয়?\
(A) Guwahati / গুৱাহাটী\
(B) Sivasagar / শিৱসাগৰ\
(C) Tezpur / তেজপুৰ\
(D) Hajo / হাজো

**3.** The Usha–Aniruddha legend is associated with which hill in Tezpur?\
ঊষা–অনিৰুদ্ধৰ কাহিনী তেজপুৰৰ কোনটো পাহাৰৰ সৈতে জড়িত?\
(A) Agnigarh / অগ্নিগড়\
(B) Nilachal / নীলাচল\
(C) Chitrachal / চিত্ৰাচল\
(D) Umananda / উমানন্দ

**4.** The Kamakhya temple is situated on which hill?\
কামাখ্যা মন্দিৰ কোনটো পাহাৰত অৱস্থিত?\
(A) Agnigarh / অগ্নিগড়\
(B) Nilachal / নীলাচল\
(C) Sukreswar / শুক্ৰেশ্বৰ\
(D) Navagraha / নৱগ্ৰহ

**5.** The chronicles of the Ahom court are called:\
আহোম ৰাজসভাৰ ইতিহাস-গ্ৰন্থসমূহক কি বোলা হয়?\
(A) Charitputhi / চৰিতপুথি\
(B) Vamsavali / বংশাৱলী\
(C) Buranji / বুৰঞ্জী\
(D) Bakhar / বখৰ

**6.** Which is regarded as the earliest inscription so far found in Assam?\
অসমত এতিয়ালৈকে পোৱা আটাইতকৈ পুৰণি অভিলেখ কোনখন বুলি গণ্য কৰা হয়?\
(A) Umachal rock inscription / উমাচল শিলালিপি\
(B) Tezpur rock inscription / তেজপুৰ শিলালিপি\
(C) Nidhanpur copper plate / নিধানপুৰ তাম্ৰফলক\
(D) Bargaon copper plate / বৰগাঁও তাম্ৰফলক

**7.** The Umachal rock inscription is located in:\
উমাচল শিলালিপি ক'ত অৱস্থিত?\
(A) Tezpur / তেজপুৰ\
(B) Golaghat / গোলাঘাট\
(C) Nagaon / নগাঁও\
(D) Guwahati / গুৱাহাটী

**8.** How many lines of writing does the Umachal rock inscription have?\
উমাচল শিলালিপিখনত কেইটা শাৰী লিখনি আছে?\
(A) 2 / ২\
(B) 12 / ১২\
(C) 76 / ৭৬\
(D) 4 / ৪

**9.** The Umachal rock inscription records the construction of a cave temple for:\
উমাচল শিলালিপিত কোন দেৱতাৰ বাবে এটা গুহা-মন্দিৰ নিৰ্মাণৰ কথা লিখা আছে?\
(A) Shiva / শিৱ\
(B) Balabhadra / বলভদ্ৰ\
(C) Surya / সূৰ্য\
(D) The Buddha / বুদ্ধ

**10.** The Tezpur rock inscription is located in which present-day district?\
তেজপুৰ শিলালিপি বৰ্তমানৰ কোনখন জিলাত অৱস্থিত?\
(A) Sonitpur / শোণিতপুৰ\
(B) Darrang / দৰং\
(C) Nagaon / নগাঁও\
(D) Biswanath / বিশ্বনাথ

**11.** The Gupta Era, used to date the Tezpur rock inscription, began in:\
তেজপুৰ শিলালিপিৰ তাৰিখত ব্যৱহৃত গুপ্ত অব্দ কেতিয়াৰ পৰা আৰম্ভ হৈছিল?\
(A) 57 BCE / খ্ৰীষ্টপূৰ্ব ৫৭\
(B) 78 CE / ৭৮ খ্ৰীষ্টাব্দ\
(C) 319–320 CE / ৩১৯–৩২০ খ্ৰীষ্টাব্দ\
(D) 606 CE / ৬০৬ খ্ৰীষ্টাব্দ

**12.** The Kamarupi script later developed into the:\
কামৰূপী লিপিৰ পৰা পিছলৈ কোনটো লিপিৰ বিকাশ ঘটে?\
(A) Kharosthi script / খৰোষ্ঠী লিপি\
(B) Tai-Ahom script / টাই-আহোম লিপি\
(C) Tamil script / তামিল লিপি\
(D) Assamese script / অসমীয়া লিপি

**13.** The Kanai-Boroxiboa inscription, one of the last Kamarupa inscriptions, uses which script?\
কামৰূপৰ শেষৰ ফালৰ অভিলেখৰ এখন কানাই-বৰশীবোৱা শিলালিপি কোন লিপিত লিখা?\
(A) Proto-Assamese script / আদি-অসমীয়া লিপি\
(B) Kharosthi script / খৰোষ্ঠী লিপি\
(C) Eastern Gupta script / পূবৰ গুপ্ত লিপি\
(D) Tai-Ahom script / টাই-আহোম লিপি

**14.** The colloquial Indo-Aryan language seen beneath the Sanskrit of the Kamarupa inscriptions is called:\
কামৰূপৰ অভিলেখৰ সংস্কৃতৰ আঁৰত থকা স্থানীয় কথিত ইণ্ডো-আৰ্য ভাষাটোক কি বোলা হয়?\
(A) Pali / পালি\
(B) Tai / টাই\
(C) Brajabuli / ব্ৰজবুলি\
(D) Kamarupi Prakrit / কামৰূপী প্ৰাকৃত

**15.** The Kamarupa inscriptions belong to which period?\
কামৰূপৰ অভিলেখসমূহ কোন সময়ছোৱাৰ?\
(A) 3rd century BCE to 1st century CE / খ্ৰীষ্টপূৰ্ব ৩য় শতিকাৰ পৰা খ্ৰীষ্টীয় ১ম শতিকালৈ\
(B) 10th to 16th century CE / খ্ৰীষ্টীয় ১০মৰ পৰা ১৬শ শতিকালৈ\
(C) 5th to early 13th century CE / খ্ৰীষ্টীয় ৫ম শতিকাৰ পৰা ১৩শ শতিকাৰ আৰম্ভণিলৈ\
(D) 13th to 19th century CE / খ্ৰীষ্টীয় ১৩শৰ পৰা ১৯শ শতিকালৈ

**16.** Bhaskaravarman ruled approximately during:\
ভাস্কৰবৰ্মনে প্ৰায় কোন সময়ছোৱাত ৰাজত্ব কৰিছিল?\
(A) c. 350–374 CE / প্ৰায় ৩৫০–৩৭৪ খ্ৰীষ্টাব্দ\
(B) c. 518–542 CE / প্ৰায় ৫১৮–৫৪২ খ্ৰীষ্টাব্দ\
(C) c. 600–650 CE / প্ৰায় ৬০০–৬৫০ খ্ৰীষ্টাব্দ\
(D) c. 815–832 CE / প্ৰায় ৮১৫–৮৩২ খ্ৰীষ্টাব্দ

**17.** Bhaskaravarman formed an alliance with:\

**18.** The common enemy of Bhaskaravarman and Harshavardhana was:\

(A) Pulakeshin II / দ্বিতীয় পুলকেশী\

(D) Yasovarman / যশোবৰ্মন

**19.** Bhaskaravarman is remembered as "Kumara" because he:\
ভাস্কৰবৰ্মনক "কুমাৰ" বুলি কিয় মনত ৰখা হয়?\

(D) Worshipped Kartikeya / তেওঁ কাৰ্তিকেয়ৰ উপাসক আছিল

**20.** A clay seal of Bhaskaravarman has been found at:\
ভাস্কৰবৰ্মনৰ এটা মাটিৰ মোহৰ ক'ত পোৱা গৈছে?\

**21.** Bhaskaravarman came to the throne after the death of his brother:\
ভাস্কৰবৰ্মন তেওঁৰ কোনজন ভাতৃৰ মৃত্যুৰ পিছত সিংহাসনত বহিছিল?\

পিতৃৰ ৰাজত্বকালত ভাস্কৰবৰ্মনক কোন ৰাজ্যৰ ৰজাই বন্দী কৰিছিল?\

**23.** Bhaskaravarman accompanied Harsha in religious processions from Pataliputra to:\
ভাস্কৰবৰ্মনে পাটলিপুত্ৰৰ পৰা কোন ঠাইলৈ হৰ্ষৰ ধৰ্মীয় শোভাযাত্ৰাত সংগ দিছিল?\

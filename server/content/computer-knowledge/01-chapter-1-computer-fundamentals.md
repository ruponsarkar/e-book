## 1.1 Revision notes / পুনৰালোচনাৰ টোকা

A **computer** is an electronic machine that accepts data (**input**), processes it according to instructions (**program**), stores it, and gives results (**output**).\
**কম্পিউটাৰ** এটা ইলেক্ট্ৰনিক যন্ত্ৰ, যিয়ে তথ্য গ্ৰহণ (ইনপুট) কৰে, নিৰ্দেশনা (প্ৰগ্ৰাম) অনুসৰি প্ৰক্ৰিয়া কৰে, সঞ্চয় কৰে আৰু ফলাফল (আউটপুট) দিয়ে।

**IPO cycle / ইনপুট–প্ৰক্ৰিয়া–আউটপুট:** Input → Process → Output, with Storage. Raw facts are **data**; processed, meaningful data is **information**.\
কেঁচা তথ্য হ'ল **data**; প্ৰক্ৰিয়াকৃত অৰ্থপূৰ্ণ তথ্য হ'ল **information**।

| Feature / বৈশিষ্ট্য | Meaning / অৰ্থ |
| --- | --- |
| Speed | Millions of instructions per second |
| Accuracy | Errors are usually human (GIGO — Garbage In, Garbage Out) |
| Storage | Holds large amounts of data |
| Diligence | Does not tire or lose concentration |
| No IQ | Cannot think on its own |

**Classification / শ্ৰেণীবিভাজন**
- By working: **analog** (continuous quantities, e.g. speedometer), **digital** (discrete 0/1), **hybrid** (both, e.g. ICU machines).
- By size: **supercomputer** (fastest; weather forecasting), **mainframe** (banks, large organisations), **minicomputer**, **microcomputer** (PCs, laptops).
- India's supercomputers include the **PARAM** series by **C-DAC**, Pune.

# Chapter 4 — Input and Output Devices / অধ্যায় ৪ — ইনপুট আৰু আউটপুট ডিভাইচ

## 4.1 Revision notes / পুনৰালোচনাৰ টোকা

| Input devices / ইনপুট ডিভাইচ | Use / ব্যৱহাৰ |
| --- | --- |
| Keyboard, mouse | Typing and pointing |
| Scanner | Converts paper documents and pictures into digital images |
| **MICR** (Magnetic Ink Character Reader) | Reads magnetic-ink numbers on bank cheques |
| **OMR** (Optical Mark Reader) | Reads filled bubbles on exam answer sheets |
| **OCR** (Optical Character Recognition) | Turns printed text into editable text |
| Barcode reader | Reads product barcodes at shops |
| Light pen, joystick, microphone, webcam, biometric scanner | Drawing, games, voice, video, fingerprint |

| Output devices / আউটপুট ডিভাইচ | Notes / টোকা |
| --- | --- |
| Monitor (VDU) | Soft copy; resolution in **pixels** |
| Printer | Hard copy; **impact** (dot-matrix) or **non-impact** (laser, inkjet); quality in **DPI** |
| Plotter | Large drawings, maps, engineering designs |
| Speaker, projector | Sound; large-screen display |

**Both input and output / দুয়োটা:** touchscreen, modem, headset with microphone.\
**Soft copy** = on screen; **hard copy** = on paper.

## 7.1 Revision notes / পুনৰালোচনাৰ টোকা

**File extension:** **.docx** (Word 2007 onward); older **.doc**. Templates: **.dotx**.
| Shortcut | Action / কাম |
| --- | --- |
| Ctrl + B / I / U | Bold / Italic / Underline |
| Ctrl + E / L / R / J | Centre / Left / Right / Justify |
| Ctrl + Z / Ctrl + Y | Undo / Redo |
| Ctrl + F / Ctrl + H | Find / Replace |
| Ctrl + Enter | Page break |
| Ctrl + K | Insert hyperlink |
| F7 | Spelling and grammar check |
| F12 | Save As |

**Features / বৈশিষ্ট্য:** **Mail Merge** (same letter to many people from a list); **Header and Footer** (text at top/bottom of every page); **Track Changes**; **Thesaurus** (Shift + F7); **Watermark**; **Page orientation** (portrait/landscape); **Margins**; **Drop Cap**.\
**Mail Merge**-এ এখন তালিকাৰ বহু লোকলৈ একেখন চিঠি তৈয়াৰ কৰে।

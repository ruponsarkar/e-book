## 9.1 Revision notes / পুনৰালোচনাৰ টোকা

- File extension **.pptx** (older .ppt); a presentation is made of **slides**.
- **Views / ভিউ:** Normal (editing), **Slide Sorter** (thumbnails, to rearrange slides), Notes Page, Reading View, **Slide Show** (full screen).
- **Transition** = effect when moving from one slide to the next; **Animation** = effect on an object (text, picture) within a slide.\
**Transition** এখন স্লাইডৰ পৰা আনখনলৈ যোৱাৰ প্ৰভাৱ; **Animation** স্লাইডৰ ভিতৰৰ বস্তুৰ প্ৰভাৱ।
- **Slide Master** controls the design of all slides at once.
- Shortcuts: **F5** (start show from the first slide), **Shift + F5** (from the current slide), **Ctrl + M** (new slide), **Esc** (end show), **B** (black screen during a show).

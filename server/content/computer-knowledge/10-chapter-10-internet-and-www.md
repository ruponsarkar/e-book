## 10.1 Revision notes / পুনৰালোচনাৰ টোকা

- The **internet** is a global network of networks. It grew out of **ARPANET** (USA, 1969).\
ইণ্টাৰনেট হ'ল নেটৱৰ্কৰ বিশ্বব্যাপী নেটৱৰ্ক।
- The **World Wide Web (WWW)** — linked web pages on the internet — was invented by **Tim Berners-Lee** in **1989** at **CERN**.
- **HTTP** (HyperText Transfer Protocol) carries web pages; **HTTPS** is its secure, encrypted form (padlock in the browser).
- **HTML** is the language used to make web pages.
- **URL** = web address, e.g. `https://www.assam.gov.in`. **Domain extensions:** .com (commercial), .org (organisation), .gov/.gov.in (government), .edu, .in (India).
- **DNS** turns domain names into **IP addresses**. **IPv4** = 32 bits (e.g. 192.168.1.1); **IPv6** = 128 bits.
- **Browser** (Chrome, Firefox, Edge, Safari) shows web pages; **search engine** (Google, Bing) finds them.
- **ISP** = Internet Service Provider (e.g. BSNL, Airtel, Jio). **Download** = receive; **upload** = send.

## 13.1 Revision notes / পুনৰালোচনাৰ টোকা

| Threat / বিপদ | What it does / কি কৰে |
| --- | --- |
| Virus | Attaches to files and spreads when they are opened |
| Worm | Spreads by itself across networks |
| Trojan horse | Looks useful but secretly harms |
| Ransomware | Locks or encrypts files and demands payment |
| Spyware / keylogger | Secretly records activity or keystrokes |
| Phishing | Fake emails, messages or sites that steal passwords or bank details |
| Vishing / smishing | Phishing by voice call / SMS |

**Protection / সুৰক্ষা:** antivirus, **firewall** (filters network traffic), software updates, strong passwords, **two-factor authentication (2FA)**, never sharing **OTP or PIN**.\
OTP বা PIN কাকো নিদিব — বেংকেও কেতিয়াও নিবিচাৰে।

**India / ভাৰত**
- **Information Technology Act, 2000** — India's main cyber law; came into force on 17 October 2000.
- **CERT-In** (Indian Computer Emergency Response Team), set up in 2004 under MeitY, handles cyber-security incidents.
- **National Cyber Crime Helpline: 1930**; complaints online at **cybercrime.gov.in**.
- **Digital Personal Data Protection (DPDP) Act, 2023**; its Rules were notified in November 2025.\
DPDP আইন ২০২৩; ইয়াৰ নিয়মাৱলী নৱেম্বৰ ২০২৫ত জাননী দিয়া হয়।

**1.** A program that spreads by attaching itself to files is a:\
ফাইলৰ সৈতে লাগি বিয়পি পৰা প্ৰগ্ৰামক কি বোলে?\
(A) Firewall / ফায়াৰৱাল\
(B) Browser / ব্ৰাউজাৰ\
(C) Compiler / কম্পাইলাৰ\
(D) Virus / ভাইৰাছ\
**Answer / উত্তৰ: (D) Virus / ভাইৰাছ**\
Explanation: VIRUS is sometimes expanded as "Vital Information Resources Under Siege". [C1]\
ব্যাখ্যা: VIRUS-ক কেতিয়াবা "Vital Information Resources Under Siege" বুলি কোৱা হয়।\
*B7-C13-0001 · Malware · Easy · ADRE-IV-P1, ADRE-IV-P2, ADRE-III-P4, SSC-CGL-T2, SSC-CHSL-T2*

**2.** Malware that locks files and demands money to unlock them is:\
ফাইল লক কৰি খুলিবলৈ টকা দাবী কৰা মেলৱেৰক কি বোলে?\
(A) Ransomware / ৰেনচমৱেৰ\
(B) Spyware / স্পাইৱেৰ\
(C) Adware / এডৱেৰ\
(D) Freeware / ফ্ৰীৱেৰ\
**Answer / উত্তৰ: (A) Ransomware / ৰেনচমৱেৰ**\
Explanation: WannaCry (2017) was a well-known ransomware attack. [C1]\
ব্যাখ্যা: WannaCry (২০১৭) এটা পৰিচিত ৰেনচমৱেৰ আক্ৰমণ।\
*B7-C13-0002 · Malware · Easy · ADRE-IV-P1, ADRE-IV-P2, ADRE-III-P4, SSC-CGL-T2, SSC-CHSL-T2*

**3.** Phishing done through SMS text messages is called:\
এছএমএছ বাৰ্তাৰ জৰিয়তে কৰা ফিচিঙক কি বোলে?\
(A) Vishing / ভিচিং\
(B) Smishing / স্মিচিং\
(C) Pharming / ফাৰ্মিং\
(D) Spoofing / স্পুফিং\
**Answer / উত্তৰ: (B) Smishing / স্মিচিং**\
Explanation: Smishing = SMS + phishing; such messages often carry a fake link. [C1]\
ব্যাখ্যা: স্মিচিং = এছএমএছ + ফিচিং; এনে বাৰ্তাত প্ৰায়ে ভুৱা লিংক থাকে।\
*B7-C13-0003 · Online fraud · Easy · ADRE-IV-P1, ADRE-IV-P2, ADRE-III-P4, SSC-CGL-T2, SSC-CHSL-T2*

**4.** Malware that looks like useful software but does harm secretly is a:\
উপকাৰী ছফ্টৱেৰ যেন লগা কিন্তু গোপনে ক্ষতি কৰা মেলৱেৰক কি বোলে?\
(A) Worm / ৱৰ্ম\
(B) Trojan horse / ট্ৰ'জান হৰ্চ\
(C) Cookie / কুকি\
(D) Patch / পেচ\
**Answer / উত্তৰ: (B) Trojan horse / ট্ৰ'জান হৰ্চ**\
Explanation: Unlike a virus, a Trojan does not copy itself. [C1]\
ব্যাখ্যা: ভাইৰাছৰ দৰে ট্ৰ'জানে নিজকে নকল নকৰে।\
*B7-C13-0004 · Malware · Moderate · ADRE-IV-P2, ADRE-III-P4, SSC-CGL-T2, SSC-CHSL-T2*

**5.** Malware that spreads by itself through a network without attaching to files is a:\
ফাইলৰ সৈতে নালাগি নিজে নেটৱৰ্কৰ জৰিয়তে বিয়পা মেলৱেৰক কি বোলে?\
(A) Virus / ভাইৰাছ\
(B) Trojan / ট্ৰ'জান\
(C) Bug / বাগ\
(D) Worm / ৱৰ্ম\
**Answer / উত্তৰ: (D) Worm / ৱৰ্ম**\
Explanation: Worms replicate on their own. [C1]\
ব্যাখ্যা: ৱৰ্মে নিজে নিজৰ প্ৰতিলিপি বনায়।\

**6.** A firewall can be implemented as:\

(A) Hardware, software or both / হাৰ্ডৱেৰ, ছফ্টৱেৰ বা দুয়োটা\
(B) Hardware only / কেৱল হাৰ্ডৱেৰ\
(C) Software only / কেৱল ছফ্টৱেৰ\
(D) A printer setting / প্ৰিণ্টাৰৰ এটা ছেটিং\
**Answer / উত্তৰ: (A) Hardware, software or both / হাৰ্ডৱেৰ, ছফ্টৱেৰ বা দুয়োটা**\
Explanation: Routers often have hardware firewalls; operating systems include software firewalls. [C1]\
ব্যাখ্যা: ৰাউটাৰত প্ৰায়ে হাৰ্ডৱেৰ ফায়াৰৱাল থাকে; অপাৰেটিং চিষ্টেমত ছফ্টৱেৰ ফায়াৰৱাল থাকে।\
*B7-C13-0006 · Protection · Moderate · ADRE-IV-P2, ADRE-III-P4, SSC-CGL-T2, SSC-CHSL-T2*

**7.** Fraud done through a phone call to get bank details is called:\
বেংকৰ তথ্য ল'বলৈ ফোন কলৰ জৰিয়তে কৰা প্ৰতাৰণাক কি বোলে?\
(A) Smishing / স্মিচিং\
(B) Hacking / হেকিং\
(C) Vishing / ভিচিং\
(D) Spoofing only / কেৱল স্পুফিং\
**Answer / উত্তৰ: (C) Vishing / ভিচিং**\

ব্যাখ্যা: ভিচিং = ফোনত ফিচিং; স্মিচিং = এছএমএছত ফিচিং।\

চাইবাৰ অপৰাধ আৰু ইলেক্ট্ৰনিক নথি সম্পৰ্কীয় ভাৰতৰ মূল আইন কোনটো?\

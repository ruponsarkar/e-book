## 14.1 Revision notes / পুনৰালোচনাৰ টোকা

| Shortcut | Action / কাম |
| --- | --- |
| Ctrl + C / X / V | Copy / Cut / Paste |
| Ctrl + A | Select all |
| Ctrl + S / Ctrl + P | Save / Print |
| Ctrl + N / Ctrl + O | New / Open |
| Alt + Tab | Switch between open windows |
| Alt + F4 | Close the active window or program |
| Windows + D | Show desktop |
| Windows + L | Lock the computer |
| Windows + E | Open File Explorer |
| Ctrl + Shift + Esc | Open Task Manager |
| F1 | Help |
| F2 | Rename a selected file |
| F5 | Refresh |
| Shift + Delete | Delete permanently (skip the Recycle Bin) |
| Print Screen (PrtSc) | Copy an image of the screen |

**Windows terms / উইণ্ড'জৰ শব্দ:** **Desktop** (main screen), **Taskbar** (bar at the bottom with Start and open programs), **Recycle Bin** (deleted files kept until emptied), **File Explorer**, **Control Panel / Settings**, **folder** (holds files), **file extension** (.exe programs, .jpg pictures, .mp3 audio, .pdf documents, .zip compressed).\
**Recycle Bin**-ত মচা ফাইল খালী নকৰালৈকে থাকে।

## 3.1 Rules / নিয়ম

| Tense / কাল | Form / গঠন | Example / উদাহৰণ |
| --- | --- | --- |
| Simple present / সাধাৰণ বৰ্তমান | V1 (+s/es) | She goes to school. |
| Present continuous / চলিত বৰ্তমান | is/am/are + V-ing | The baby is sleeping. |
| Present perfect / পুৰা বৰ্তমান | has/have + V3 | I have finished. |
| Present perfect continuous / চলিত পুৰা বৰ্তমান | has/have been + V-ing | It has been raining. |
| Simple past / সাধাৰণ অতীত | V2 | He visited Guwahati. |
| Past continuous / চলিত অতীত | was/were + V-ing | They were having dinner. |
| Past perfect / পুৰা অতীত | had + V3 | The train had left. |
| Simple future / সাধাৰণ ভৱিষ্যৎ | will + V1 | I will call you. |
| Future perfect / পুৰা ভৱিষ্যৎ | will have + V3 | They will have finished. |

- **Since** + point of time; **for** + period: *since 2020*, *for three days*.\
**Since** + সময়ৰ বিন্দু; **for** + সময়ৰ পৰিসৰ।
- Do not use the present perfect with a finished past time (*yesterday, last year, in 2019*).\
সম্পূৰ্ণ অতীত সময়ৰ (*yesterday, last year, in 2019*) সৈতে পুৰা বৰ্তমান ব্যৱহাৰ নকৰিব।
- **Stative verbs** (know, believe, like, own) are not normally used in continuous forms.\
**অৱস্থাবাচক ক্ৰিয়া** (know, believe, like, own) সাধাৰণতে চলিত ৰূপত ব্যৱহাৰ নহয়।
- After **did / does / do / modals**, use the base verb: *did not go*, *can swim*.\
**did / does / do / modal**-ৰ পিছত মূল ক্ৰিয়া বহে।
- Conditionals: *If + present → will*; *If + past (were) → would*; *If + had V3 → would have V3*.\
চৰ্তসাপেক্ষ বাক্য: *If + বৰ্তমান → will*; *If + অতীত (were) → would*; *If + had V3 → would have V3*।
- Fixed pairs: **hardly/scarcely … when**, **no sooner … than**; **It is high time + past**; **I wish + were**.\
নিৰ্দিষ্ট যোৰ: **hardly/scarcely … when**, **no sooner … than**; **It is high time + অতীত**; **I wish + were**।

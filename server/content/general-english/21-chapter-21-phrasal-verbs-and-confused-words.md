## 21.1 Rules and revision notes / নিয়ম আৰু পুনৰালোচনাৰ টোকা

**Phrasal verbs / ফ্ৰেজেল ভাৰ্ব** (verb + particle with a new meaning)

| Phrasal verb | Meaning |
| --- | --- |
| bring up | raise a child; mention a topic |
| call off | cancel |
| carry out | perform, complete |
| come across | find by chance |
| give in | surrender, yield |
| look after | take care of |
| look into | investigate |
| put off | postpone |
| put up with | tolerate |
| run out of | have no more left |
| set up | establish |
| turn down | reject |

**Words often confused / বিভ্ৰান্তিকৰ শব্দ**

| Pair | Difference |
| --- | --- |
| accept / except | take willingly / leave out |
| advice / advise | noun / verb |
| affect / effect | verb (influence) / noun (result) |
| principal / principle | head of a school, main / a rule or belief |
| stationary / stationery | not moving / paper, pens |
| complement / compliment | something that completes / praise |
| loose / lose | not tight / fail to keep |
| council / counsel | a group of people / advice |

### B. Words often confused / বিভ্ৰান্তিকৰ শব্দ

**10.** Choose the correct option to fill in the blank: **I need your ___ on this matter.**\
খালী ঠাইত বহুৱাবলৈ শুদ্ধ বিকল্পটো বাছি উলিওৱা:\
(A) advise\
(B) advice\
(C) advices\
(D) adviced\
**Answer / উত্তৰ: (B) advice**\
Explanation: 'Advice' is the noun (uncountable); 'advise' is the verb.\
ব্যাখ্যা: 'Advice' বিশেষ্য (অগণনীয়); 'advise' ক্ৰিয়া।\

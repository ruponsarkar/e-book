## 16.1 Revision notes / পুনৰালোচনাৰ টোকা

| Term / শব্দ | Meaning / অৰ্থ |
| --- | --- |

| RAM / ROM | RAM is temporary (volatile) memory; ROM keeps its data without power |

### A. Hardware and memory / হাৰ্ডৱেৰ আৰু মেমৰি

**1.** Who is called the "father of the computer"?\
"কম্পিউটাৰৰ পিতৃ" বুলি কাক কোৱা হয়?\
(A) Alan Turing / এলান টুৰিং\
(B) Charles Babbage / চাৰ্লছ বেবেজ\
(C) Bill Gates / বিল গেটছ\
(D) Tim Berners-Lee / টিম বাৰ্নাৰ্ছ-লি\
**Answer / উত্তৰ: (B) Charles Babbage / চাৰ্লছ বেবেজ**\
Explanation: Babbage designed the Analytical Engine in the 19th century. [G1]\
ব্যাখ্যা: বেবেজে ঊনবিংশ শতিকাত এনালিটিকেল ইঞ্জিনৰ নক্সা কৰিছিল।\
*B9-C16-0001 · History · Easy · ADRE-IV-P1, ADRE-IV-P2, ADRE-III-P3, ADRE-III-P5, APC, SSC*

**2.** Which part of a computer is called its "brain"?\
কম্পিউটাৰৰ কোনটো অংশক ইয়াৰ "মগজু" বোলা হয়?\
(A) CPU / চিপিইউ\
(B) Monitor / মনিটৰ\
(C) Hard disk / হাৰ্ড ডিস্ক\
(D) Keyboard / কীব'ৰ্ড\
**Answer / উত্তৰ: (A) CPU / চিপিইউ**\
Explanation: The Central Processing Unit carries out instructions and calculations. [G1]\
ব্যাখ্যা: চেণ্ট্ৰেল প্ৰচেছিং ইউনিটে নিৰ্দেশ আৰু গণনা সম্পন্ন কৰে।\
*B9-C16-0002 · Hardware · Easy · ADRE-IV-P1, ADRE-IV-P2, ADRE-III-P3, ADRE-III-P5, APC, SSC*

**3.** Which memory loses its contents when the power is switched off?\
বিদ্যুৎ বন্ধ কৰিলে কোন মেমৰিৰ তথ্য হেৰায়?\
(A) ROM / ৰম\
(B) Hard disk / হাৰ্ড ডিস্ক\
(C) Pen drive / পেন ড্ৰাইভ\
(D) RAM / ৰেম\
**Answer / উত্তৰ: (D) RAM / ৰেম**\
Explanation: RAM is volatile; ROM, hard disks and pen drives keep data without power. [G1]\
ব্যাখ্যা: ৰেম অস্থায়ী; ৰম, হাৰ্ড ডিস্ক আৰু পেন ড্ৰাইভে বিদ্যুৎ নাথাকিলেও তথ্য ৰাখে।\
*B9-C16-0003 · Memory · Easy · ADRE-IV-P1, ADRE-IV-P2, ADRE-III-P3, ADRE-III-P5, APC, SSC*

**4.** One byte is equal to:\
এক বাইট কিমানৰ সমান?\
(A) 4 bits / ৪ বিট\
(B) 16 bits / ১৬ বিট\
(C) 1,024 bits / ১,০২৪ বিট\
(D) 8 bits / ৮ বিট\
**Answer / উত্তৰ: (D) 8 bits / ৮ বিট**\
Explanation: 1 kilobyte = 1,024 bytes. [G1]\
ব্যাখ্যা: ১ কিল'বাইট = ১,০২৪ বাইট।\
*B9-C16-0004 · Memory · Easy · ADRE-IV-P1, ADRE-IV-P2, ADRE-III-P3, ADRE-III-P5, APC, SSC*

**5.** Which of these is an output device?\
তলৰ কোনটো আউটপুট যন্ত্ৰ?\
(A) Printer / প্ৰিণ্টাৰ\
(B) Keyboard / কীব'ৰ্ড\
(C) Mouse / মাউছ\
(D) Scanner / স্কেনাৰ\
**Answer / উত্তৰ: (A) Printer / প্ৰিণ্টাৰ**\
Explanation: Keyboard, mouse and scanner put data into the computer. [G1]\
ব্যাখ্যা: কীব'ৰ্ড, মাউছ আৰু স্কেনাৰে কম্পিউটাৰলৈ তথ্য দিয়ে।\
*B9-C16-0005 · Hardware · Easy · ADRE-IV-P1, ADRE-IV-P2, ADRE-III-P3, ADRE-III-P5, APC, SSC*

**6.** Computers store all data in the:\
কম্পিউটাৰে সকলো তথ্য কোন পদ্ধতিত সংৰক্ষণ কৰে?\
(A) Decimal system / দশমিক পদ্ধতি\
(B) Binary system (0 and 1) / দ্বিমিক পদ্ধতি (০ আৰু ১)\
(C) Roman numerals / ৰোমান সংখ্যা\
(D) Hexadecimal system only / কেৱল ষোড়শমিক পদ্ধতি\
**Answer / উত্তৰ: (B) Binary system (0 and 1) / দ্বিমিক পদ্ধতি (০ আৰু ১)**\
Explanation: Each bit is either 0 or 1. [G1]\
ব্যাখ্যা: প্ৰতিটো বিট ০ বা ১।\
*B9-C16-0006 · Data · Easy · ADRE-IV-P1, ADRE-IV-P2, ADRE-III-P3, ADRE-III-P5, APC, SSC*

### B. Software and the internet / ছফ্টৱেৰ আৰু ইণ্টাৰনেট

**7.** Which of these is an operating system?\
তলৰ কোনটো অপাৰেটিং চিষ্টেম?\
(A) MS Word / এমএছ ৱৰ্ড\
(B) Google Chrome / গুগল ক্ৰ'ম\
(C) Linux / লিনাক্স\
(D) MS Excel / এমএছ এক্সেল\
**Answer / উত্তৰ: (C) Linux / লিনাক্স**\
Explanation: Word and Excel are application programs; Chrome is a web browser. [G1]\
ব্যাখ্যা: ৱৰ্ড আৰু এক্সেল এপ্লিকেচন প্ৰ'গ্ৰাম; ক্ৰ'ম এটা ৱেব ব্ৰাউজাৰ।\
*B9-C16-0007 · Software · Easy · ADRE-IV-P1, ADRE-IV-P2, ADRE-III-P3, ADRE-III-P5, APC, SSC*

**8.** The World Wide Web was invented by:\
ৱৰ্ল্ড ৱাইড ৱেব কোনে উদ্ভাৱন কৰিছিল?\
(A) Tim Berners-Lee / টিম বাৰ্নাৰ্ছ-লি\
(B) Charles Babbage / চাৰ্লছ বেবেজ\
(C) Steve Jobs / ষ্টিভ জবছ\
(D) Vint Cerf / ভিণ্ট চাৰ্ফ\
**Answer / উত্তৰ: (A) Tim Berners-Lee / টিম বাৰ্নাৰ্ছ-লি**\
Explanation: He proposed it at CERN in 1989. Vint Cerf co-designed the TCP/IP protocols of the internet. [G1]\
ব্যাখ্যা: তেওঁ ১৯৮৯ত চাৰ্নত প্ৰস্তাৱ দিছিল। ভিণ্ট চাৰ্ফে ইণ্টাৰনেটৰ টিচিপি/আইপি প্ৰট'কলৰ নক্সাত অংশ লৈছিল।\
*B9-C16-0008 · Internet · Moderate · ADRE-IV-P2, ADRE-III-P3, ADRE-III-P4, ADRE-III-P5, APC, APSI, SSC*

**9.** The keyboard shortcut Ctrl+Z is used to:\
Ctrl+Z শ্বৰ্টকাটৰ কাম কি?\
(A) Save a file / ফাইল সংৰক্ষণ কৰা\
(B) Copy text / লেখা কপি কৰা\
(C) Undo the last action / শেষৰ কামটো বাতিল কৰা\
(D) Close a window / উইণ্ড' বন্ধ কৰা\
**Answer / উত্তৰ: (C) Undo the last action / শেষৰ কামটো বাতিল কৰা**\
Explanation: Ctrl+S saves, Ctrl+C copies and Alt+F4 closes a window in Windows. [G1]\
ব্যাখ্যা: Ctrl+S য়ে সংৰক্ষণ, Ctrl+C য়ে কপি আৰু Windowsত Alt+F4 য়ে উইণ্ড' বন্ধ কৰে।\
*B9-C16-0009 · Shortcuts · Easy · ADRE-IV-P1, ADRE-IV-P2, ADRE-III-P3, ADRE-III-P5, APC, SSC*

**10.** MS Excel is mainly used for:\
এমএছ এক্সেল মূলতঃ কিহৰ বাবে ব্যৱহাৰ কৰা হয়?\
(A) Making presentations / উপস্থাপন প্ৰস্তুত কৰা\
(B) Writing letters / চিঠি লিখা\
(C) Browsing the internet / ইণ্টাৰনেট চোৱা\
(D) Spreadsheets and calculations / স্প্ৰেডশ্বীট আৰু গণনা\
**Answer / উত্তৰ: (D) Spreadsheets and calculations / স্প্ৰেডশ্বীট আৰু গণনা**\
Explanation: PowerPoint is for presentations and Word for documents. [G1]\
ব্যাখ্যা: পাৱাৰপইণ্ট উপস্থাপনৰ বাবে আৰু ৱৰ্ড নথিৰ বাবে।\
*B9-C16-0010 · Software · Easy · ADRE-IV-P1, ADRE-IV-P2, ADRE-III-P3, ADRE-III-P5, APC, SSC*

**11.** A firewall in a computer network is used to:\
কম্পিউটাৰ নেটৱৰ্কত ফায়াৰৱাল কিহৰ বাবে ব্যৱহাৰ কৰা হয়?\
(A) Block unauthorised access / অনুমতি নোহোৱা প্ৰৱেশ বন্ধ কৰা\
(B) Speed up the processor / প্ৰচেছৰ দ্ৰুত কৰা\
(C) Cool the computer / কম্পিউটাৰ ঠাণ্ডা ৰখা\
(D) Print documents / নথি ছপা কৰা\
**Answer / উত্তৰ: (A) Block unauthorised access / অনুমতি নোহোৱা প্ৰৱেশ বন্ধ কৰা**\
Explanation: It filters network traffic using security rules. [G1]\
ব্যাখ্যা: ই সুৰক্ষাৰ নিয়ম অনুসৰি নেটৱৰ্কৰ তথ্য চালনি কৰে।\
*B9-C16-0011 · Security · Easy · ADRE-IV-P1, ADRE-IV-P2, ADRE-III-P3, ADRE-III-P5, APC, SSC*

**12.** "Phishing" means:\
"ফিচিং" মানে কি?\
(A) Repairing a computer network / কম্পিউটাৰ নেটৱৰ্ক মেৰামতি\
(B) Downloading music legally / বৈধভাৱে সংগীত ডাউনল'ড কৰা\
(C) Tricking people into revealing passwords or bank details / প্ৰতাৰণা কৰি পাছৱৰ্ড বা বেংকৰ তথ্য লোৱা\
(D) Cleaning a virus / ভাইৰাছ আঁতৰোৱা\
**Answer / উত্তৰ: (C) Tricking people into revealing passwords or bank details / প্ৰতাৰণা কৰি পাছৱৰ্ড বা বেংকৰ তথ্য লোৱা**\
Explanation: Fake emails, messages or websites pretend to be a bank or company; never share OTPs or passwords. [G1]\
ব্যাখ্যা: ভুৱা ইমেইল, বাৰ্তা বা ৱেবছাইটে বেংক বা কোম্পানী যেন দেখুৱায়; অ'টিপি বা পাছৱৰ্ড কেতিয়াও নিদিব।\
*B9-C16-0012 · Security · Easy · ADRE-IV-P1, ADRE-IV-P2, ADRE-III-P3, ADRE-III-P5, APC, SSC*

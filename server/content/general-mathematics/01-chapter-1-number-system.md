**Divisibility rules / বিভাজ্যতাৰ নিয়ম:** 2 – last digit even; 3 – digit sum divisible by 3; 4 – last two digits; 5 – ends in 0 or 5; 8 – last three digits; 9 – digit sum divisible by 9; 11 – difference of alternate digit sums is 0 or a multiple of 11.\
২ – শেষৰ অংক যুগ্ম; ৩ – অংকৰ যোগফল ৩-ৰে বিভাজ্য; ৪ – শেষৰ দুটা অংক; ৫ – শেষত ০ বা ৫; ৮ – শেষৰ তিনিটা অংক; ৯ – অংকৰ যোগফল ৯-ৰে বিভাজ্য; ১১ – একান্তৰ অংকৰ যোগফলৰ পাৰ্থক্য ০ বা ১১-ৰ গুণিতক।

**Formulas / সূত্ৰ:** 1 + 2 + … + n = n(n + 1)/2; sum of first n odd numbers = n²; first n even numbers = n(n + 1); 1² + 2² + … + n² = n(n + 1)(2n + 1)/6.\
**Number of factors / গুণনীয়কৰ সংখ্যা:** if N = aᵖ × bᵠ × cʳ, then (p + 1)(q + 1)(r + 1).\
**Unit digit cycles / একক অংকৰ চক্ৰ:** 2 → 2, 4, 8, 6; 3 → 3, 9, 7, 1; 7 → 7, 9, 3, 1; 4 → 4, 6; 9 → 9, 1; 0, 1, 5, 6 stay the same.\
**Zeros at the end of n! / n!-ৰ শেষৰ শূন্য:** ⌊n/5⌋ + ⌊n/25⌋ + ⌊n/125⌋ + …\
**Recurring decimals / পুনৰাবৃত্ত দশমিক:** 0.aaa… = a/9; 0.ababab… = ab/99; 0.abbb… = (ab − a)/90.

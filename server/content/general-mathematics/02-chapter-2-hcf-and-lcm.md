## 2.1 Concepts and formulas / ধাৰণা আৰু সূত্ৰ

- **HCF (Highest Common Factor)** — the largest number that divides all the given numbers. Take the **lowest** powers of the **common** primes.\
**গ.সা.গু. (গৰিষ্ঠ সাধাৰণ গুণনীয়ক)** — প্ৰদত্ত সকলো সংখ্যাক হৰণ কৰা আটাইতকৈ ডাঙৰ সংখ্যা। **উমৈহতীয়া** মৌলিকৰ **নিম্নতম** ঘাত লওক।
- **LCM (Lowest Common Multiple)** — the smallest number divisible by all the given numbers. Take the **highest** powers of **all** primes.\
**ল.সা.গু. (লঘিষ্ঠ সাধাৰণ গুণিতক)** — প্ৰদত্ত সকলো সংখ্যাৰে বিভাজ্য আটাইতকৈ সৰু সংখ্যা। **সকলো** মৌলিকৰ **সৰ্বোচ্চ** ঘাত লওক।

| Formula / সূত্ৰ | Use / ব্যৱহাৰ |
| --- | --- |
| HCF × LCM = product of the two numbers / দুটা সংখ্যাৰ পূৰণফল | Find a missing number / নোহোৱা সংখ্যা উলিয়াবলৈ |
| HCF of fractions = HCF(numerators) ÷ LCM(denominators) | ভগ্নাংশৰ গ.সা.গু. |
| LCM of fractions = LCM(numerators) ÷ HCF(denominators) | ভগ্নাংশৰ ল.সা.গু. |
| Largest number dividing a, b, c leaving remainder r = HCF(a − r, b − r, c − r) | একে ভাগশেষ থাকিলে |
| Largest number leaving the same (unknown) remainder = HCF of the differences | ভাগশেষ অজ্ঞাত হ'লে পাৰ্থক্যৰ গ.সা.গু. |
| Smallest number leaving remainder r when divided by a, b, c = LCM(a, b, c) + r | একে ভাগশেষৰ ক্ষুদ্ৰতম সংখ্যা |

**Word problems:** "together again / meet again / ring together" → **LCM**; "largest size / largest measure / largest tile" → **HCF**.\
**শাব্দিক অংক:** "পুনৰ একেলগে / লগ পাব / একেলগে বাজিব" → **ল.সা.গু.**; "আটাইতকৈ ডাঙৰ জোখ / টাইল" → **গ.সা.গু.**।

**Division method for HCF:** divide the larger number by the smaller, then the divisor by the remainder, until the remainder is 0; the last divisor is the HCF.\
**হৰণ পদ্ধতি:** ডাঙৰ সংখ্যাক সৰুটোৰে হৰণ কৰক, তাৰ পিছত হৰকক ভাগশেষেৰে, ভাগশেষ ০ নোহোৱালৈকে; শেষৰ হৰকেই গ.সা.গু.।

## 3.1 Rules and shortcuts / নিয়ম আৰু চমু পদ্ধতি

**BODMAS / VBODMAS:** Brackets (innermost first: ( ) → { } → [ ]) → Orders (powers and roots) → Division and Multiplication (left to right) → Addition and Subtraction (left to right).\
**BODMAS:** বন্ধনী (ভিতৰৰ পৰা: ( ) → { } → [ ]) → ঘাত আৰু মূল → হৰণ আৰু পূৰণ (বাওঁৰ পৰা সোঁফাললৈ) → যোগ আৰু বিয়োগ (বাওঁৰ পৰা সোঁফাললৈ)।

| Identity / অভেদ | Shortcut example / উদাহৰণ |
| --- | --- |
| (a + b)² = a² + 2ab + b² | 103² = 10000 + 600 + 9 = 10609 |
| (a − b)² = a² − 2ab + b² | 98² = 10000 − 400 + 4 = 9604 |
| a² − b² = (a + b)(a − b) | 103 × 97 = 100² − 3² = 9991 |
| (a + b)² − (a² + b²) = 2ab | (3 + 5)² − (9 + 25) = 30 |

- **Decimals:** in multiplication, count the total decimal places; in division, multiply both numbers by the same power of 10 to remove the decimal from the divisor.\
**দশমিক:** পূৰণত মুঠ দশমিক স্থান গণনা কৰক; হৰণত হৰকৰ দশমিক আঁতৰাবলৈ দুয়োটাকে ১০-ৰ একে ঘাতেৰে পূৰণ কৰক।
- **Fractions:** add or subtract after making the denominators equal (use the LCM); to divide, multiply by the reciprocal.\
**ভগ্নাংশ:** হৰ সমান কৰি (ল.সা.গু. ব্যৱহাৰ কৰি) যোগ বা বিয়োগ কৰক; হৰণ কৰিবলৈ বিপৰীত ভগ্নাংশেৰে পূৰণ কৰক।
- **Percent:** x% of y = x × y / 100; 25% = 1/4, 50% = 1/2, 20% = 1/5, 12.5% = 1/8.\
**শতাংশ:** yৰ x% = x × y / ১০০।

## 5.1 Concepts and formulas / ধাৰণা আৰু সূত্ৰ

| Rule / নিয়ম | Formula / সূত্ৰ |
| --- | --- |
| x% of y / yৰ x% | x × y / 100 (and x% of y = y% of x) |
| Successive change a% then b% / ক্ৰমিক পৰিৱৰ্তন | a + b + ab/100 (use minus signs for decreases) |
| A is r% more than B → B is less than A by / A, Bতকৈ r% বেছি | r/(100 + r) × 100 % |
| Price up r% → cut consumption by / দাম r% বাঢ়িলে ব্যৱহাৰ কমাব | r/(100 + r) × 100 % |
| Growth for n years / n বছৰৰ বৃদ্ধি | P(1 + r/100)ⁿ; depreciation P(1 − r/100)ⁿ |

**Useful fractions / উপযোগী ভগ্নাংশ:** 1/2 = 50%, 1/3 = 33⅓%, 1/4 = 25%, 1/5 = 20%, 1/6 = 16⅔%, 1/8 = 12.5%, 1/10 = 10%.

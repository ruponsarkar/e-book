## 6.1 Concepts and formulas / ধাৰণা আৰু সূত্ৰ

- **Ratio** a : b compares two quantities of the same kind; **proportion** a : b = c : d means ad = bc.\
**অনুপাত** a : b ই একে জাতীয় দুটা ৰাশিৰ তুলনা কৰে; **সমানুপাত** a : b = c : d মানে ad = bc।

| Term / পদ | Formula / সূত্ৰ |
| --- | --- |
| Fourth proportional to a, b, c / চতুৰ্থ সমানুপাতী | bc / a |
| Third proportional to a, b / তৃতীয় সমানুপাতী | b² / a |
| Mean proportional of a, b / মধ্য সমানুপাতী | √(ab) |
| Duplicate / triplicate ratio / দ্বিগুণিত / ত্ৰিগুণিত | a² : b², a³ : b³ |
| Share of A when N is divided in a : b / ভাগ | N × a/(a + b) |

- To combine A : B and B : C, make the B terms equal. For fractional ratios, multiply all terms by the LCM of the denominators.\
A : B আৰু B : C একত্ৰিত কৰিবলৈ B পদ সমান কৰক। ভগ্নাংশৰ অনুপাতত সকলো পদক হৰবোৰৰ ল.সা.গু.ৰে পূৰণ কৰক।

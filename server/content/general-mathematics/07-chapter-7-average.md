## 7.1 Concepts and formulas / ধাৰণা আৰু সূত্ৰ

- **Average = sum of observations ÷ number of observations.**\
**গড় = পৰ্যবেক্ষণৰ যোগফল ÷ পৰ্যবেক্ষণৰ সংখ্যা।**

| Result / ফল | Formula / সূত্ৰ |
| --- | --- |
| First n natural numbers / প্ৰথম nটা স্বাভাৱিক সংখ্যা | (n + 1)/2 |
| First n even numbers / প্ৰথম nটা যুগ্ম সংখ্যা | n + 1 |
| First n odd numbers / প্ৰথম nটা অযুগ্ম সংখ্যা | n |
| Numbers in AP / সমান্তৰ শ্ৰেণী | (first + last)/2 = middle term |
| Average speed over equal distances / সমান দূৰত্বত গড় দ্ৰুতি | 2xy/(x + y) |
| Combined average / সংযুক্ত গড় | (n₁a₁ + n₂a₂)/(n₁ + n₂) |

- **Replacement:** new value = old value + (number of items × change in average).\
**সলনি:** নতুন মান = পুৰণি মান + (সংখ্যা × গড়ৰ পৰিৱৰ্তন)।

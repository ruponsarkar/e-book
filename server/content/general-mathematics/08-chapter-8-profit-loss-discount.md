## 8.1 Concepts and formulas / ধাৰণা আৰু সূত্ৰ

| Term / পদ | Formula / সূত্ৰ |
| --- | --- |
| Profit % / লাভ % | (SP − CP)/CP × 100 |
| SP with gain g% / লাভত বিক্ৰয়মূল্য | CP × (100 + g)/100 |
| CP from SP / বিক্ৰয়মূল্যৰ পৰা ক্ৰয়মূল্য | SP × 100/(100 + g) or SP × 100/(100 − l) |
| SP after discount d% / ৰেহাইৰ পিছত | MP × (100 − d)/100 |
| Successive discounts a%, b% / ক্ৰমিক ৰেহাই | a + b − ab/100 |
| Same SP, x% gain and x% loss / একে বিক্ৰয়মূল্য | always a loss of x²/100 % |
| False weight / ভুল ওজন | gain % = error/(true value − error) × 100 |

- Profit and loss are always calculated on the **cost price**; discount is calculated on the **marked price**.\
লাভ আৰু লোকচান সদায় **ক্ৰয়মূল্য**ৰ ওপৰত; ৰেহাই **চিহ্নিত মূল্য**ৰ ওপৰত গণনা কৰা হয়।

## 13.1 Concepts and formulas / ধাৰণা আৰু সূত্ৰ

- If A can finish a job in **a** days, A's **one-day work = 1/a**.\
Aয়ে এটা কাম **a** দিনত কৰিব পাৰিলে Aৰ **এদিনৰ কাম = ১/a**।

| Result / ফল | Formula / সূত্ৰ |
| --- | --- |
| A and B together / একেলগে | ab/(a + b) days |
| A, B, C together / তিনিজন | 1 / (1/a + 1/b + 1/c) |
| Work equivalence / কামৰ সমতা | M₁D₁H₁/W₁ = M₂D₂H₂/W₂ |
| Sharing wages / মজুৰি ভাগ | in the ratio of one-day work (efficiency) |

- **LCM method:** take the total work as the LCM of the days; each worker's rate is then a whole number of units per day.\
**ল.সা.গু. পদ্ধতি:** মুঠ কাম দিনবোৰৰ ল.সা.গু. ধৰক; তেতিয়া প্ৰতিজনৰ হাৰ দিনে এটা পূৰ্ণ সংখ্যা একক হয়।

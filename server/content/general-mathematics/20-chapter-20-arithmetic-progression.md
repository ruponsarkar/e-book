## 20.1 Concepts and formulas / ধাৰণা আৰু সূত্ৰ

| Item / বিষয় | Formula / সূত্ৰ |
| --- | --- |
| nth term / n-তম পদ | aₙ = a + (n − 1)d |
| Sum of n terms / nটা পদৰ যোগফল | Sₙ = n/2 [2a + (n − 1)d] = n/2 (first + last) |
| Number of terms / পদৰ সংখ্যা | n = (last − first)/d + 1 |
| nth term from Sₙ / Sₙৰ পৰা পদ | aₙ = Sₙ − Sₙ₋₁ |
| Sums / যোগফল | 1 + 2 + … + n = n(n + 1)/2; 1 + 3 + … (n terms) = n² |

- For three numbers in AP, take **a − d, a, a + d**; for four, take **a − 3d, a − d, a + d, a + 3d**.\

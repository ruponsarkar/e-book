## 22.1 Concepts and formulas / ধাৰণা আৰু সূত্ৰ

| Item / বিষয় | Formula / সূত্ৰ |
| --- | --- |
| Distance / দূৰত্ব | √[(x₂ − x₁)² + (y₂ − y₁)²] |
| Midpoint / মধ্যবিন্দু | ((x₁ + x₂)/2, (y₁ + y₂)/2) |
| Section formula m : n / বিভাজন সূত্ৰ | ((mx₂ + nx₁)/(m + n), (my₂ + ny₁)/(m + n)) |
| Slope / নতি | (y₂ − y₁)/(x₂ − x₁); for y = mx + c the slope is m |
| Area of a triangle / ত্ৰিভুজৰ কালি | ½ |x₁(y₂ − y₃) + x₂(y₃ − y₁) + x₃(y₁ − y₂)| |

- Parallel lines have **equal slopes**; perpendicular lines have slopes whose product is **−1**. Quadrants: I (+, +), II (−, +), III (−, −), IV (+, −).\
সমান্তৰাল ৰেখাৰ **নতি সমান**; লম্ব ৰেখাৰ নতিৰ পূৰণফল **−১**। পাদ: I (+, +), II (−, +), III (−, −), IV (+, −)।

## 23.1 Concepts and formulas / ধাৰণা আৰু সূত্ৰ

| Figure / চিত্ৰ | Area / কালি | Perimeter / পৰিসীমা |
| --- | --- | --- |
| Rectangle / আয়ত | l × b | 2(l + b); diagonal √(l² + b²) |
| Square / বৰ্গ | a² | 4a; diagonal a√2 |
| Triangle / ত্ৰিভুজ | ½ × base × height; Heron √[s(s − a)(s − b)(s − c)] | a + b + c |
| Equilateral triangle / সমবাহু | (√3/4)a² | 3a |
| Rhombus / ৰম্বাছ | ½ d₁d₂ | 4a |
| Trapezium / ট্ৰেপিজিয়াম | ½ (a + b) h | sum of sides |
| Circle / বৃত্ত | πr² | 2πr |
| Sector of angle θ / বৃত্তকলা | (θ/360)πr² | arc = (θ/360)2πr |

- Distance covered by a wheel in one revolution = its **circumference**.\
এপাকত চকাই অতিক্ৰম কৰা দূৰত্ব = ইয়াৰ **পৰিধি**।

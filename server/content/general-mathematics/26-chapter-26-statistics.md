## 26.1 Concepts and formulas / ধাৰণা আৰু সূত্ৰ

| Measure / জোখ | How to find / নিৰ্ণয় পদ্ধতি |
| --- | --- |
| Mean / গড় | sum ÷ number; for a table Σfx/Σf |
| Median / মধ্যমা | middle value after sorting; for an even count, average of the two middle values |
| Mode / বহুলক | the value that occurs most often |
| Range / পৰিসৰ | highest − lowest |
| Empirical relation / অভিজ্ঞতামূলক সম্বন্ধ | Mode ≈ 3 Median − 2 Mean |

- Adding a constant k to every value adds k to the mean, median and mode; multiplying every value by k multiplies them by k.\
প্ৰতিটো মানত k যোগ কৰিলে গড়, মধ্যমা আৰু বহুলকত k যোগ হয়; kৰে পূৰণ কৰিলে সেইবোৰো kৰে পূৰণ হয়।

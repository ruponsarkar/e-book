# Chapter 1 — Analogy / অধ্যায় ১ — সাদৃশ্য

*Level: Grade IV to Graduate (Levels 1–3 = Easy, Moderate, Hard) · All answers checked by computation where numeric*\
*স্তৰ: চতুৰ্থ শ্ৰেণীৰ পৰা স্নাতক (সহজ, মধ্যম, কঠিন)*

## 1.1 Method / পদ্ধতি

An analogy question gives a pair of words, numbers or letters (**A : B**) and asks you to complete a second pair (**C : ?**) with the same relation. Read "**::**" as "in the same way as".\
সাদৃশ্যৰ প্ৰশ্নত এযোৰ শব্দ, সংখ্যা বা বৰ্ণ (**A : B**) দিয়া থাকে আৰু একে সম্পৰ্কৰে দ্বিতীয় যোৰটো (**C : ?**) সম্পূৰ্ণ কৰিবলৈ কোৱা হয়। "**::**" চিনক "যিদৰে … তেনেদৰে" বুলি পঢ়ক।

1. **Name the relation in a short sentence.** "A doctor *works in* a hospital."\
**এটা চুটি বাক্যত সম্পৰ্কটো কওক।** "চিকিৎসকে চিকিৎসালয়ত *কাম কৰে*।"
2. **Apply the same sentence to C.** "A teacher *works in* … a school."\
**একে বাক্যটো C-ৰ ক্ষেত্ৰত প্ৰয়োগ কৰক।** "শিক্ষকে … বিদ্যালয়ত *কাম কৰে*।"
3. **If two options fit, make the relation more exact** (e.g. "young one of", not just "related to").\
**দুটা বিকল্প মিলিলে সম্পৰ্কটো আৰু নিখুঁত কৰক** (যেনে "পোৱালি", কেৱল "সম্পৰ্কিত" নহয়)।

| Common relations / সাধাৰণ সম্পৰ্ক | Example / উদাহৰণ |
| --- | --- |
| Worker : place of work / কৰ্মী : কৰ্মস্থান | Doctor : Hospital |
| Tool : use / সঁজুলি : ব্যৱহাৰ | Pen : Write |
| Animal : young one / প্ৰাণী : পোৱালি | Cow : Calf |
| Instrument : what it measures / যন্ত্ৰ : কি জোখে | Thermometer : Temperature |
| Part : whole / অংশ : সম্পূৰ্ণ | Petal : Flower |
| Opposites / বিপৰীত | Hot : Cold |
| Country/state : capital or currency / দেশ বা ৰাজ্য : ৰাজধানী বা মুদ্ৰা | Assam : Dispur |

**Number analogies:** test square (n²), cube (n³), n² ± 1, n³ ± 1, n × (n + 1), halving or doubling.\
**সংখ্যাৰ সাদৃশ্য:** বৰ্গ (n²), ঘন (n³), n² ± ১, n³ ± ১, n × (n + ১), আধা বা দুগুণ পৰীক্ষা কৰক।

**Letter analogies:** write the alphabet with positions (A = 1 … Z = 26). Check forward/backward shifts and opposite letters (positions adding up to 27: A–Z, B–Y, C–X …).\
**বৰ্ণৰ সাদৃশ্য:** স্থানসহ বৰ্ণমালা লিখক (A = ১ … Z = ২৬)। আগলৈ বা পিছলৈ স্থানান্তৰ আৰু বিপৰীত বৰ্ণ (স্থানৰ যোগফল ২৭: A–Z, B–Y, C–X …) পৰীক্ষা কৰক।

**Memory trick for opposites:** "**AZ BY CX DW EV**" … and "**GT**" (G = 7, T = 20), "**MN**" (13, 14).\
**বিপৰীত বৰ্ণ মনত ৰখাৰ কৌশল:** "**AZ BY CX DW EV**" … আৰু "**GT**", "**MN**"।

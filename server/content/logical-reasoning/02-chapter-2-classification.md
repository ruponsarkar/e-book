*স্তৰ: চতুৰ্থ শ্ৰেণীৰ পৰা স্নাতক (সহজ, মধ্যম, কঠিন)*

## 2.1 Method / পদ্ধতি

Classification questions give four items; three share a property and one does not. Find the **common property of three**, then the item that lacks it.\
শ্ৰেণীবিভাজনৰ প্ৰশ্নত চাৰিটা বস্তু থাকে; তিনিটাৰ এটা উমৈহতীয়া গুণ থাকে আৰু এটাৰ নাথাকে। প্ৰথমে **তিনিটাৰ উমৈহতীয়া গুণটো** বিচাৰক, তাৰ পিছত সেই গুণ নথকাটো বাছক।

1. **Words:** check category (fruit/vegetable, metal/non-metal, planet/satellite), place (state, country), use, or 2D/3D shape.\
**শব্দ:** শ্ৰেণী (ফল/শাক-পাচলি, ধাতু/অধাতু, গ্ৰহ/উপগ্ৰহ), স্থান (ৰাজ্য, দেশ), ব্যৱহাৰ বা দ্বিমাত্ৰিক/ত্ৰিমাত্ৰিক আকাৰ পৰীক্ষা কৰক।
2. **Numbers:** check prime, even/odd, perfect square or cube, multiples, sum of digits.\
**সংখ্যা:** মৌলিক, যুগ্ম/অযুগ্ম, পূৰ্ণবৰ্গ বা পূৰ্ণঘন, গুণিতক, অংকৰ যোগফল পৰীক্ষা কৰক।
3. **Number pairs:** find the rule linking the two numbers in three pairs (n → n², n → n³ …).\
**সংখ্যাৰ যোৰ:** তিনিটা যোৰত দুয়োটা সংখ্যাৰ সম্পৰ্কৰ নিয়ম বিচাৰক (n → n², n → n³ …)।
4. **Letter groups:** check gaps between letters, vowels/consonants, opposite pairs and positions.\
**বৰ্ণগোট:** বৰ্ণৰ মাজৰ ব্যৱধান, স্বৰ/ব্যঞ্জন, বিপৰীত যোৰ আৰু স্থান পৰীক্ষা কৰক।

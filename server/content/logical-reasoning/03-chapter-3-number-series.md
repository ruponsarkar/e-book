## 3.1 Method / পদ্ধতি

A number series follows a rule. Test the rules below **in this order**; most exam series are solved by step 1 or 2.\
সংখ্যা শৃংখলাই এটা নিয়ম মানি চলে। তলৰ নিয়মবোৰ **এই ক্ৰমত** পৰীক্ষা কৰক; পৰীক্ষাৰ বেছিভাগ শৃংখলা ১ বা ২ নং ধাপতে সমাধান হয়।

1. **Differences:** write the difference between neighbouring terms. Constant → add/subtract; growing by a pattern (1, 2, 3 … or 3, 5, 7 …) → second-level series.\
**পাৰ্থক্য:** ওচৰা-ওচৰি পদৰ পাৰ্থক্য লিখক। স্থিৰ হ'লে → যোগ/বিয়োগ; আৰ্হি মানি বাঢ়িলে (১, ২, ৩ … বা ৩, ৫, ৭ …) → দ্বিতীয় স্তৰৰ শৃংখলা।
2. **Ratios:** if terms grow fast, divide neighbours: ×2, ×3, or ×2, ×3, ×4 …\
**অনুপাত:** পদবোৰ বেগেৰে বাঢ়িলে ওচৰৰ পদেৰে হৰণ কৰক: ×২, ×৩, বা ×২, ×৩, ×৪ …
3. **Mixed rules:** ×2 + 1, ×2 − 1, ×3 + 1 …\
**মিশ্ৰ নিয়ম:** ×২ + ১, ×২ − ১, ×৩ + ১ …
4. **Special numbers:** squares, cubes, primes, n² ± 1, n³ ± 1, n(n + 1).\
**বিশেষ সংখ্যা:** বৰ্গ, ঘন, মৌলিক, n² ± ১, n³ ± ১, n(n + ১)।
5. **Sum of previous terms:** each term = sum of the two before it (Fibonacci type).\
**আগৰ পদৰ যোগফল:** প্ৰতিটো পদ = আগৰ দুটা পদৰ যোগফল (ফিবোনাচি ধৰণৰ)।
6. **Alternating rules:** ×3, ÷2, ×3, ÷2 …\
**পাল পাতি নিয়ম:** ×৩, ÷২, ×৩, ÷২ …

**Worked example:** 4, 7, 12, 19, 28, ? → differences 3, 5, 7, 9 → next difference 11 → **39**.\
**উদাহৰণ:** ৪, ৭, ১২, ১৯, ২৮, ? → পাৰ্থক্য ৩, ৫, ৭, ৯ → পিছৰ পাৰ্থক্য ১১ → **৩৯**।

**Wrong-term questions:** find the rule from most of the terms, then the one term that breaks it.\
**ভুল পদৰ প্ৰশ্ন:** বেছিভাগ পদৰ পৰা নিয়মটো উলিয়াওক, তাৰ পিছত নিয়ম ভংগ কৰা পদটো বিচাৰক।

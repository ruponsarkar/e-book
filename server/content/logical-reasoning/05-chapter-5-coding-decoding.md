## 5.1 Method / পদ্ধতি

Compare the word and its code letter by letter, and write the position change under each letter.\
শব্দ আৰু ইয়াৰ সংকেত বৰ্ণ অনুসৰি তুলনা কৰক, আৰু প্ৰতিটো বৰ্ণৰ তলত স্থানৰ সলনি লিখক।

| Type | How to spot it / কেনেকৈ চিনিব |
| --- | --- |
| Shift (+k or −k) | Every letter moves the same number of places / প্ৰতিটো বৰ্ণ একে সংখ্যক স্থান সৰে |
| Opposite letter | Positions of letter and code add to 27 (A ↔ Z) / বৰ্ণ আৰু সংকেতৰ স্থানৰ যোগফল ২৭ |
| Reverse | The code reads the word backwards, maybe with a shift / সংকেতটো শব্দটোৰ ওলোটা |
| Letter values | Letters are replaced by A = 1 … Z = 26, or their sum / বৰ্ণৰ ঠাইত স্থান-সংখ্যা বা যোগফল |
| Sentence codes | Find the word common to two sentences and the code common to both / দুটা বাক্যৰ উমৈহতীয়া শব্দ আৰু সংকেত বিচাৰক |
| Substitution | First find the real answer, then give its code name / প্ৰথমে প্ৰকৃত উত্তৰ, তাৰ পিছত তাৰ সাংকেতিক নাম |

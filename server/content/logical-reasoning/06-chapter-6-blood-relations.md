## 6.1 Method / পদ্ধতি

Draw a small family tree as you read: **+** for male, **−** for female, a double line for a married couple and a vertical line for parent and child.\
পঢ়ি যোৱাৰ লগে লগে এখন সৰু বংশতালিকা আঁকক: পুৰুষৰ বাবে **+**, মহিলাৰ বাবে **−**, স্বামী-স্ত্ৰীৰ বাবে দুডাল ৰেখা আৰু পিতৃ-মাতৃ আৰু সন্তানৰ বাবে থিয় ৰেখা।

| Phrase / বাক্যাংশ | Means / মানে |
| --- | --- |
| Father's or mother's father / পিতৃ বা মাতৃৰ পিতৃ | Grandfather / ককা |
| Father's brother / পিতৃৰ ভাতৃ | Paternal uncle / খুৰা বা দদাই |
| Mother's brother / মাতৃৰ ভাতৃ | Maternal uncle / মামা |
| Father's sister / পিতৃৰ ভগ্নী | Paternal aunt / পেহী |
| Mother's sister / মাতৃৰ ভগ্নী | Maternal aunt / মাহী |
| Brother's son / ভাতৃৰ পুত্ৰ | Nephew / ভতিজা |
| Son's wife / পুত্ৰৰ পত্নী | Daughter-in-law / বোৱাৰী |
| Husband's or wife's father / স্বামী বা পত্নীৰ পিতৃ | Father-in-law / শহুৰ |

**Watch for "only son", "only child", "no brother":** they usually point back to the speaker.\
**"একমাত্ৰ পুত্ৰ", "একমাত্ৰ সন্তান", "ভাতৃ নাই" লক্ষ্য কৰক:** সাধাৰণতে ই বক্তাজনক নিজকে বুজায়।

**1.** Pointing to a man, Rina says, "He is the son of my grandfather's only son." How is the man related to Rina?\
এজন মানুহলৈ আঙুলিয়াই ৰীণাই ক'লে, "তেওঁ মোৰ ককাৰ একমাত্ৰ পুত্ৰৰ পুত্ৰ।" মানুহজন ৰীণাৰ কি হয়?\
(A) Brother / ভাতৃ\
(B) Son / পুত্ৰ\
(C) Paternal uncle / খুৰা বা দদাই (পিতৃৰ ভাতৃ)\
(D) Cousin / সম্পৰ্কীয় ভাই বা ভনী (cousin)\
**Answer / উত্তৰ: (A) Brother / ভাতৃ**\
Solution: Grandfather's only son = Rina's father. The father's son = Rina's **brother**.\
সমাধান: ককাৰ একমাত্ৰ পুত্ৰ = ৰীণাৰ পিতৃ। পিতৃৰ পুত্ৰ = ৰীণাৰ **ভাতৃ**।\

**3.** X is the husband of Y. Z is the daughter of Y. W is the brother of X. How is W related to Z?\
X, Yৰ স্বামী। Z, Yৰ কন্যা। W, Xৰ ভাতৃ। W, Zৰ কি হয়?\
(A) Maternal uncle / মামা (মাতৃৰ ভাতৃ)\
(B) Brother / ভাতৃ\
(C) Paternal uncle / খুৰা বা দদাই (পিতৃৰ ভাতৃ)\
(D) Father / পিতৃ\
**Answer / উত্তৰ: (C) Paternal uncle / খুৰা বা দদাই (পিতৃৰ ভাতৃ)**\
Solution: X is Z's father (husband of Z's mother). W is X's brother, so W is Z's **paternal uncle**.\
সমাধান: X হৈছে Zৰ পিতৃ (Zৰ মাতৃৰ স্বামী)। W, Xৰ ভাতৃ, সেয়ে W, Zৰ **খুৰা বা দদাই**।\

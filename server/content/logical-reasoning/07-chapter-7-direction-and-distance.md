## 7.1 Method / পদ্ধতি

Draw the path on rough paper with North at the top. A **right turn** is clockwise and a **left turn** is anticlockwise.\
উত্তৰ ওপৰফালে ৰাখি পথটো আঁকক। **সোঁফালে ঘূৰা** মানে ঘড়ীৰ কাঁটাৰ দিশত আৰু **বাওঁফালে ঘূৰা** মানে বিপৰীত দিশত।

| Facing / মুখ | Right turn / সোঁফালে | Left turn / বাওঁফালে |
| --- | --- | --- |
| North / উত্তৰ | East / পূব | West / পশ্চিম |
| East / পূব | South / দক্ষিণ | North / উত্তৰ |
| South / দক্ষিণ | West / পশ্চিম | East / পূব |
| West / পশ্চিম | North / উত্তৰ | South / দক্ষিণ |

**Distance:** add up all the East–West movement and all the North–South movement separately, then use Pythagoras: d = √(x² + y²). Useful triples: 3-4-5, 6-8-10, 5-12-13, 8-15-17.\
**দূৰত্ব:** পূব-পশ্চিম আৰু উত্তৰ-দক্ষিণ গতিবোৰ বেলেগে বেলেগে যোগ কৰক, তাৰ পিছত পাইথাগোৰাছ: d = √(x² + y²)। ৩-৪-৫, ৬-৮-১০, ৫-১২-১৩, ৮-১৫-১৭।

**Shadows:** in the morning the Sun is in the East, so shadows fall West; in the evening shadows fall East. At noon there is almost no shadow.\
**ছাঁ:** পুৱা সূৰ্য পূবত থাকে, সেয়ে ছাঁ পশ্চিমলৈ পৰে; সন্ধিয়া ছাঁ পূবলৈ পৰে। দুপৰীয়া প্ৰায় ছাঁ নাথাকে।

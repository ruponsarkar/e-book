## 9.1 Method / পদ্ধতি

**Symbol substitution:** first rewrite the whole expression with the real signs, then apply **BODMAS** (Brackets, Of, Division, Multiplication, Addition, Subtraction).\
**চিন সলনি:** প্ৰথমে গোটেই ৰাশিটো প্ৰকৃত চিনেৰে লিখক, তাৰ পিছত **BODMAS** মানক।

**Inequalities:** to compare two letters in a chain, read only the signs between them.\
**অসমতা:** শিকলিৰ দুটা বৰ্ণ তুলনা কৰিবলৈ কেৱল সিহঁতৰ মাজৰ চিনবোৰ চাওক।

| Signs between / মাজৰ চিন | Result / ফল |
| --- | --- |
| Only >, ≥, = (at least one >) | Definitely > |
| Only ≥ and = | Definitely ≥ |
| Only = | Definitely = |
| Both > and < appear / > আৰু < দুয়োটা থাকিলে | No definite relation / নিশ্চিত সম্পৰ্ক নাই |

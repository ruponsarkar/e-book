## 12.1 Method / পদ্ধতি

Treat every statement as true, even if it sounds odd ("All pens are books"). A conclusion **follows** only if it is true in **every** diagram you can draw for the statements.\
প্ৰতিটো বিবৃতি সত্য বুলি ধৰক, অদ্ভুত শুনালেও ("সকলো কলম কিতাপ")। সকলো সম্ভাৱ্য চিত্ৰত সত্য হ'লেহে সিদ্ধান্ত **সত্য**।

| Statement / বিবৃতি | Always gives / সদায় পোৱা যায় | Never gives / কেতিয়াও নহয় |
| --- | --- | --- |
| All A are B | Some A are B; Some B are A | All B are A |
| Some A are B | Some B are A | All A are B |
| No A are B | No B are A; Some A are not B | Some A are B |
| Some A are not B | — | Any "Some B are not A" |

**Quick rules:** All + All = All; All + No = No; Some + All = Some; Some + No = Some … are not; Some + Some = no definite conclusion; No + No = no definite conclusion.\
**চমু নিয়ম:** সকলো + সকলো = সকলো; সকলো + কোনো নহয় = কোনো নহয়; কিছুমান + সকলো = কিছুমান; কিছুমান + কোনো নহয় = কিছুমান … নহয়; কিছুমান + কিছুমান = নিশ্চিত সিদ্ধান্ত নাই।

**1.** Statements: All pens are books. All books are tables. Conclusions: I. All pens are tables.  II. Some tables are pens.\
বিবৃতি: সকলো কলম কিতাপ। সকলো কিতাপ মেজ। সিদ্ধান্ত: I. সকলো কলম মেজ।  II. কিছুমান মেজ কলম।\
(A) Only conclusion I follows / কেৱল সিদ্ধান্ত I সত্য\
(B) Only conclusion II follows / কেৱল সিদ্ধান্ত II সত্য\
(C) Both I and II follow / I আৰু II দুয়োটা সত্য\
(D) Neither I nor II follows / I বা II কোনোটোৱেই সত্য নহয়\
**Answer / উত্তৰ: (C) Both I and II follow / I আৰু II দুয়োটা সত্য**\
Solution: Drawing every possible Venn diagram for the statements: conclusion I is true in all of them; conclusion II is true in all of them. Answer: **Both I and II follow**.\
সমাধান: বিবৃতিৰ সকলো সম্ভাৱ্য ভেন চিত্ৰ আঁকিলে: সিদ্ধান্ত I সকলোতে সত্য; সিদ্ধান্ত II সকলোতে সত্য। উত্তৰ: **I আৰু II দুয়োটা সত্য**।\

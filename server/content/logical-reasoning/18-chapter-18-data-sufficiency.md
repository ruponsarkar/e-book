## 18.1 Method / পদ্ধতি

You do **not** have to find the answer, only decide whether the statements give enough information to find **one definite** answer. Check statement I alone, then II alone, and only then the two together.\
উত্তৰ উলিয়াব **নালাগে**, কেৱল বিবৃতিবোৰে **এটা নিশ্চিত** উত্তৰৰ বাবে যথেষ্ট তথ্য দিয়ে নে নিদিয়ে নিৰ্ণয় কৰক। প্ৰথমে কেৱল I, তাৰ পিছত কেৱল II, তাৰ পিছতহে দুয়োটা একেলগে পৰীক্ষা কৰক।

**Trap:** a statement that gives two possible values (such as x² = 25 → x = ±5) is **not** sufficient.\
**ফান্দ:** দুটা সম্ভাৱ্য মান দিয়া বিবৃতি (যেনে x² = ২৫ → x = ±৫) যথেষ্ট **নহয়**।

*In this book the four options are: (A) I alone, (B) II alone, (C) either alone, (D) both together. Some exams add a fifth option, "neither is sufficient".*\
*এই কিতাপত চাৰিটা বিকল্প: (A) কেৱল I, (B) কেৱল II, (C) যিকোনো এটা, (D) দুয়োটা একেলগে। কিছুমান পৰীক্ষাত পঞ্চম বিকল্প "কোনোটোৱেই যথেষ্ট নহয়" থাকে।*

**1.** Question: What is the value of x?  Statements: I. 3x + 5 = 20  II. x² = 25\
প্ৰশ্ন: xৰ মান কিমান?  বিবৃতি: I. ৩x + ৫ = ২০  II. x² = ২৫\

(C) Either statement alone is sufficient / যিকোনো এটা বিবৃতিয়েই অকলে যথেষ্ট\
(D) Both statements together are needed / দুয়োটা বিবৃতি একেলগে লাগিব\
**Answer / উত্তৰ: (A) Statement I alone is sufficient, but statement II alone is not / কেৱল বিবৃতি I যথেষ্ট, বিবৃতি II অকলে যথেষ্ট নহয়**\
Solution: I gives x = 5. II gives x = 5 or −5, so it is not enough. Answer: **Statement I alone is sufficient, but statement II alone is not**.\

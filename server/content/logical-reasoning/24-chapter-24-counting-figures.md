## 24.1 Method / পদ্ধতি

Count in a fixed order: single small parts first, then pairs, then larger groups. For standard figures, use the formulas below.\
এটা নিৰ্দিষ্ট ক্ৰমত গণক: প্ৰথমে এটা এটা সৰু ভাগ, তাৰ পিছত যোৰ, তাৰ পিছত ডাঙৰ গোট। সাধাৰণ চিত্ৰৰ বাবে তলৰ সূত্ৰ ব্যৱহাৰ কৰক।

| Figure / চিত্ৰ | Formula / সূত্ৰ |
| --- | --- |
| Triangle split into m parts by lines from the top / শীৰ্ষৰ পৰা ৰেখাৰে m ভাগ | m(m + 1)/2 triangles |
| n × n grid of squares / n × n বৰ্গৰ জালি | 1² + 2² + … + n² squares |
| m × n grid / m × n জালি | C(m + 1, 2) × C(n + 1, 2) rectangles |
| Equilateral triangle with side n / বাহু n থকা সমবাহু ত্ৰিভুজ | ⌊n(n + 2)(2n + 1)/8⌋ triangles |
| n points on a line / ৰেখাৰ n বিন্দু | n(n − 1)/2 segments |
| Polygon with n sides / n বাহুৰ বহুভুজ | n(n − 3)/2 diagonals |
